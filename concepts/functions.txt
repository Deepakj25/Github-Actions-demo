      these are case-insenitive



| Function      | Returns true when           |
| ------------- | --------------------------- |
| `success()`   | Everything before succeeded    default behaviour|
| `failure()`   | Something failed            |
| `always()`    | Always                      |
| `cancelled()` | Workflow was cancelled      |
